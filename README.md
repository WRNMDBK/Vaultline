# Vaultline

**1.0 初版 · Windows 11 离线隐私信息管理工具**

Vaultline 用目录和标签整理账号、密码、API Key 等信息，支持按路径精确查找账号或字段。保险库存放在本机并加密，无需注册账号或连接云服务。

## 安装与首次使用

1. 双击 `release\Vaultline-Setup.exe`，选择程序位置和数据位置。
2. 从桌面或开始菜单打开 **Vaultline**。
3. 首次启动设置至少 12 个字符的主密码，再次输入确认。
4. 创建分组并保存账号，以后使用同一主密码解锁。

安装包可单独分享，不需要源码、开发工具或其他文件，也不包含你的账号数据。程序使用 Windows 11 自带的 .NET Framework 4.8 或更新版本。安装包尚未进行商业代码签名，系统可能显示“未知发布者”。

请妥善保管主密码；遗失后无法找回保险库内容。

## 数据位置

| 内容 | 默认位置 |
|---|---|
| 程序 | `%LOCALAPPDATA%\Programs\Vaultline` |
| 数据 | `%LOCALAPPDATA%\Vaultline\Data` |
| 保险库 | 数据目录中的 `vault.jx` |
| 上次保存的副本 | 数据目录中的 `vault.jx.bak` |

`%LOCALAPPDATA%` 通常是 `C:\Users\你的用户名\AppData\Local`。安装时可以改用其他本地目录，安装目录内的 `data-path.txt` 会记录该位置。

程序与数据分开保存。删除源码不影响已安装程序；卸载会保留数据。如果手动移动数据目录，请同步修改 `data-path.txt` 后再启动。

## 分组、标签与账号

点击 **＋ 分组**，输入完整路径，例如 `account/wechat` 或 `工作/服务器`，上级目录会自动创建。左侧目录树可逐层展开，中间列表中的分组可双击进入。选中行以金色显示。

打开分组，点击 **＋ 账号**，填写完整路径、隐私级别和 JSON 内容。例如，路径为 `account/wechat/work-account`：

```json
{
  "微信号": "my-work-id",
  "password": "在此填写密码",
  "绑定的手机号": "在此填写手机号",
  "绑定的银行卡": "在此填写银行卡"
}
```

路径最后一段 `work-account` 是标签。同一软件的另一个账号可使用 `account/wechat/social-account`。标签在同一目录下必须唯一。

JSON 支持中文或英文字段、嵌套对象、数组、数字和空值。每个账号是一个独立 JSON 对象；账号与目录一起写入加密保险库，不会另存明文账号文件。

普通、敏感、机密是信息整理标签，全部使用相同的加密和隐藏保护，并非不同用户的访问权限。

- **编辑 / 移动**：选中账号后编辑字段或完整路径；选中分组后修改分组路径。
- **删除**：删除账号，或删除分组及全部子目录、账号；执行前会确认。

## 路径搜索

在顶部输入后按 Enter，或点击 **搜索 / 跳转**。

| 输入示例 | 结果 |
|---|---|
| `account/wechat` | 打开分组 |
| `account/wechat/work-account` | 定位账号 |
| `account/wechat/work-account/password` | 定位密码字段 |
| `account/wechat/work-account/bank/card` | 定位嵌套字段 |
| `account/wechat/work-account/cards/0` | 定位数组第一项 |
| `work` | 按目录路径与标签模糊查找 |

目录和标签不区分大小写，字段名区分大小写。字段名包含 `/` 时使用 `~1`，包含 `~` 时使用 `~0`。模糊搜索不会扫描秘密字段值。

## 查看与复制

详情默认隐藏，点击 **显示 30 秒** 临时查看，到时重新隐藏，也可以手动隐藏。

**复制内容** 按字段顺序复制值，每项一行，不带字段名、JSON 括号或引号。例如：

```text
demo@example.test
your-password
```

只想复制密码时，先搜索到 `/password`，再复制。成功提示为“已复制内容”。应用不定时清空剪贴板，锁定、退出时也不清空。

## 全部导出与一键导入

工具栏顺序为 **导出数据 → 一键导入 → 帮助**。

点击 **导出数据**，选择位置，保存包含全部目录、空分组、账号标签、级别和原始字段的 JSON 文件。

点击 **一键导入**，选择 Vaultline 导出的 JSON 文件。程序检查格式后，与当前保险库合并并加密保存：

- 相同路径、内容与级别的账号跳过。
- 同路径但内容不同的账号追加 `-import-2` 等后缀，保留双方。
- 分组路径被账号占用时，会改名导入分组并保留层级。
- 无效文件不会替换现有数据。导入不改变当前保险库的主密码。

导出 JSON 是明文，包含原始秘密字段。需要加密的长期备份时，请使用“加密备份”。

## 加密备份与恢复

**加密备份** 将保险库保存为独立 `.jx` 文件。建议定期把备份存放到另一块可靠介质。

**恢复备份** 需要选择备份文件并输入备份时的主密码。确认后会替换当前保险库；替换前自动保留恢复前的加密副本。

**主密码** 可以更改当前保险库的密码。历史备份仍使用备份时的旧密码。

如主文件损坏，可关闭程序，把损坏文件另存，再将有效的 `vault.jx.bak` 复制为 `vault.jx`，使用该副本保存时的密码解锁。

## 锁定与快捷键

- **锁定** 或 `Ctrl+L`：立即锁定。
- `Ctrl+F`：聚焦搜索框。
- 闲置 5 分钟或 Windows 锁屏时自动锁定。
- 锁定会丢弃尚未保存的编辑内容，请及时保存。

## 安装升级与源码

使用相同安装目录升级时，安装器会读取原数据位置。请先退出 Vaultline，再安装，保留原数据目录即可继续使用账号和主密码。

桌面程序采用 C# + WinForms。保险库使用 AES-256-CBC、HMAC-SHA256 与 PBKDF2-HMAC-SHA256（600,000 次迭代）。保存采用原子替换，文件锁阻止多个实例同时写入。

本地加密不能代替系统安全保护，本项目尚未接受独立安全审计。

`src` 为程序和安装器源码，`tests` 为验证结果，`release` 为独立安装包。在项目根目录用 PowerShell 构建、测试：

```powershell
.\build.ps1
Start-Process .\dist\Vaultline.exe -ArgumentList '--self-test' -Wait
Get-Content .\tests\test-results.txt
```
